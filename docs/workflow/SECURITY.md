[SECURITY](../../SECURITY.md) directs vulnerability reports to the documented private developer mailbox and asks reporters not to open public issues. It states no paid bounty and supports latest default-branch state unless a repository says otherwise. These are published source commitments, not proof of mailbox delivery or a new authority to send messages.

Do not add private client details, operational runbooks, credentials or internal incident payloads to the profile/defaults. A security issue's detail belongs in the authorized private channel. No user communication is triggered by reading the policy.
