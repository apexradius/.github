# Security Policy

## Reporting a vulnerability

Email **dev@apexradius.io** with a description of the issue, the affected
repository, and steps to reproduce. Please do not open a public issue for
security reports.

We aim to acknowledge reports within a few business days and will keep you
updated as we investigate. We do not currently run a paid bug-bounty program;
responsible disclosure is appreciated and credited where welcome.

## Supported versions

Unless a repository states otherwise, only the latest default-branch state is
supported.
